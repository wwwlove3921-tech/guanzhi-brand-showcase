## 文件

- `index.html`：网页入口。
- `assets/`：页面图片、网页兼容的视频副本及视频封面。
- `.nojekyll`：使用 GitHub Pages 直接发布静态文件。

视频使用 MP4 容器和 H.264 / AAC 编码；开启 fast start，便于边加载边播放。网页副本保留原视频时长和分辨率。原始高码率视频保留在素材提供者本地。
